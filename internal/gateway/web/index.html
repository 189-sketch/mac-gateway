Fleet

Enter a dashboard key to see your machines and jobs.

Create one on the gateway server. An admin key can also manage API keys, remove machines and run tests:
sudo -u fleet /usr/local/bin/fleet-gateway key add admin --admin --data /var/lib/fleet

A key made with --dashboard instead can only view status: it can't run jobs or read their input or results. The key stays in this tab and is forgotten when you close it.
